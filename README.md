# Order Book and Matching Engine

This is a C++ implementation of an electronic order book and matching engine, built incrementally to explore trading systems, price-time priority, trade execution, data structures.

## Completed stages
Stage 1 — Order representation
Stage 2 — Basic order book
Stage 3 — Price-time priority
Stage 4 — Matching engine
Stage 5 — Order management and trade history

## Current development stage
Stage 6 — Data structures and performance

## Language
C++
